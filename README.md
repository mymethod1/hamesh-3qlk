# Mind Margin | هامش عقلك 🧠📝

A minimalist, lightweight web tool designed for distraction-free brainstorming and quick idea organization. 

## 🚀 About the Project
**Mind Margin** is a productivity-focused tool that allows users to capture their thoughts instantly without the clutter of complex interfaces. It’s designed for thinkers, writers, and developers who need a "margin" to dump their ideas and organize them later.

## ✨ Key Features
- **Distraction-Free UI:** Clean interface focused entirely on your content.
- **Lightweight & Fast:** Minimal load times for instant capturing.
- **Productivity-First:** Designed to reduce cognitive load and enhance focus.
- **Responsive Design:** Accessible from any device (Mobile, Tablet, Desktop).

## 🛠️ Tech Stack
- **Frontend:** HTML5, CSS3, JavaScript (ES6+).
- **Hosting:** Optimized for web performance.
